# Notes for Reviewer — Samsung TV Seller Office

> Copie o texto abaixo (em inglês) para o campo **Notes for Reviewer** ao submeter o `.wgt` na Samsung Seller Office.

---

## Texto para o Revisor (Inglês)

```text
App Overview:
NetTV is a neutral IPTV/HLS media player ("bring your own playlist" model). It contains NO preloaded channels, playlists, or media content of any kind.

How to Test (100% Remote Control):
1. Launch the app. The Onboarding screen displays the legal notice and asks the user to add a source.
2. Select "M3U / M3U8 Playlist" (default).
3. Enter any source name (e.g., "Demo Stream") and use one of the following legal, public-domain / open-license HLS test streams:
   - Big Buck Bunny (Blender Foundation, CC-BY 3.0):
     https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8
   - Apple HTTP Live Streaming Test Stream:
     https://devstreaming-cdn.apple.com/videos/streaming/examples/img_bipbop_adv_example_fmp4/master.m3u8
4. Press "Connect and Sync" (Conectar e Sincronizar).
5. Navigate using Arrow keys / OK / Return:
   - Open "Live TV" (TV ao Vivo) and press OK on the stream to launch the full-screen video player.
   - Use Play/Pause, Info, and Return keys to toggle controls and return to the menu.
   - Open "Settings" (Configurações) to switch language (pt-BR / en / es), adjust font size, view Terms & Privacy, or open "Diagnostics" (Diagnóstico).
   - Press Return on the main menu root to verify the Exit confirmation modal.
```
